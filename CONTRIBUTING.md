# Como contribuir

1. Pegue uma tarefa nas Issues e avise o grupo.
2. Crie uma branch a partir da `main`: `feature/nome-curto` ou `fix/nome-curto`.
3. Faça commits pequenos no formato `tipo: descrição` (`feat`, `fix`, `docs`, `refactor`, `test`).
4. Abra um pull request para a `main` descrevendo o que mudou; outra pessoa revisa.
5. Nunca suba senhas ou chaves: use `.env` (ignorado) e mantenha o `.env.example` atualizado.

## Regras de commit

- O autor do commit é sempre quem fez a contribuição. Não inclua `Co-Authored-By` nem qualquer linha de atribuição a ferramentas de IA nas mensagens de commit ou nos pull requests.
- A pasta `docs/` fica somente na máquina local e não é versionada (está no `.gitignore`).
